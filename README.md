# homebrew-tap

Official [Homebrew](https://brew.sh/) tap for [Brief CLI](https://briefhq.ai).

## Install

```bash
brew install brief-hq/tap/brief
```

This automatically taps this repository and installs the `brief` formula.

Alternatively:

```bash
brew tap brief-hq/tap
brew install brief
```

## Upgrade

```bash
brew upgrade brief
```

## Uninstall

```bash
brew uninstall brief
brew untap brief-hq/tap
```

## Requirements

- [Homebrew](https://brew.sh/)
- Node.js 22+ (installed automatically as a dependency)
